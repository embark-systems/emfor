## Change notes

These pending tasks of the first plan were cancelled on 2026-11-12, not completed. Spike 1 showed the system liblmdb and PHP `dba` cannot read the daemon's store, so the client now bundles the daemon's LMDB through cargo-c (design "One Rust core, exported to C with cargo-c" and "LMDB exit rule").
- Old 1.2 (FreeBSD CI step for the system-liblmdb and `dba` checks) is replaced by 1.3, which runs spike 2.
- Old 4.1 to 4.4 (hand-written C client with embedded cJSON and MD5, linked with the system liblmdb, its C unit tests and a cJSON conformance runner) are replaced by 4.1 (C API from the Rust crate and a conformance runner through it) and 4.2 (C test programs against the installed `libemfor`).
