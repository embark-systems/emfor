## 2. emfor status

- [x] 2.1 依「status 做成 emfor 的子指令」、「只讀設定檔的 store 表」與「唯讀開啟 LMDB 且先確認檔案存在」實作 "Status reads the store read-only" [after: 1.1]：clap 子指令 `status`（`--config` 改為 global），config 模組提供只解析 `[store]` 的函式，status 以唯讀方式開 store 並一次讀出 meta 與全部 `svc/` 記錄成 `Snapshot`；store 不存在、格式版本不符的訊息依 design Implementation Contract。驗證：`daemon.rs` 新增測試涵蓋 spec 情境 "Status beside a running daemon"（daemon 持續寫心跳）、"Store missing"（結束碼 2、未建立 store 與 `-lock`）、"Rest of the config is not validated"；格式版本 `2` 的 store 以單元測試確認結束碼 2 與訊息；既有 daemon 測試（不帶子指令、`--check-config`）全部通過。
