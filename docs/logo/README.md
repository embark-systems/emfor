# emfor logo (draft)

Three dots: two filled (healthy members), one ring (the member that is down).
The colours come from the embark.systems logo.

| Name | Value |
| --- | --- |
| green | `#213b20` |
| burgundy | `#7d1730` |
| cream | `#eae9e4` |
| burgundy on dark | `#d9566e` |

Files: `emfor-mark*.svg` (mark; plain, reversed, mono), `emfor-avatar.svg`,
`emfor-favicon.svg`, `emfor-favicon-dark.svg`, `emfor-wordmark*.svg`.
The lettering in the wordmark is drawn as paths, so it needs no font.

This is a draft: nothing uses it yet.
